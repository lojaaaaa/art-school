АРТ-СТАРТ — сайт кружка рисования

СТРУКТУРА
  index.html   — разметка страницы
  style.css    — все стили
  script.js    — вся логика (карусели, счётчики, увеличение фото, копирование контактов)
  images/      — все изображения

Откройте index.html в браузере — всё подключается автоматически.
Не переименовывайте и не переносите файлы отдельно друг от друга.

КАК ЗАМЕНИТЬ ФОТО
Серые картинки с подписями «ФОТО 1, ФОТО 2…» — заглушки. Положите свою фотографию
в ту же папку с ТЕМ ЖЕ именем (и расширением .jpg) — и она появится на сайте.
Пропорции подгоняются автоматически (обрезка по центру).

  images/hero/hero-1.jpg … hero-3.jpg      — 3 фото в главном блоке (рамки: фиолетовая, розовая, жёлтая)
  images/program/block-01-1.jpg … block-10-3.jpg
        — программа курса: block-НОМЕР БЛОКА-НОМЕР ФОТО (10 блоков × 3 фото, листаются стрелками)
  images/students/student-1.jpg … student-4.jpg — раздел «Наши учащиеся»

УЖЕ ЗАПОЛНЕНО (ваши изображения из исходного файла)
  images/logo.png                          — логотип «Маяк»
  images/teacher/teacher.jpg               — фото педагога
  images/teacher/work-1.jpg … work-3.jpg   — работы педагога
  images/maps/school-36.jpg, school-153.jpg — карты адресов

ЕЩЁ НЕ ЗАПОЛНЕНО
  Ссылки на запись и на Telegram-канал (в index.html стоят «#»).
  Шрифты подключаются с Google Fonts — нужен интернет.
